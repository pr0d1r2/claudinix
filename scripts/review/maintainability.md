# Maintainability
Find what will make the next change to this code harder or riskier than it needs to be.
- Duplication that will drift, names that mislead, comments that no longer match the code.
- Code that does not read like its neighbours: idiom, structure, comment density.
- Tests that pin implementation details instead of behaviour, or are hard to read.
- Generated files edited by hand, or a source changed without its generated output.
